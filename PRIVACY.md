# Privacy Policy

Last updated: September 14, 2026

Bitty-Note is a local-first desktop application. It does not require an account and does not include analytics, advertising, telemetry, or crash-reporting services.

## Data stored on your device

- Notes are stored as Markdown files in the folder selected by the user.
- Archived notes are stored in the `归档` subfolder.
- Application preferences, including the selected storage folder, language, window state, editor settings, and update state, are stored locally.

Bitty-Note does not upload note contents or application preferences.

## Network access

When automatic updates are enabled, Velopack-packaged releases contact GitHub at most once every 24 hours to check public Bitty-Note release metadata and silently download an available update. A manual check also contacts GitHub. The update is installed the next time the app starts, after Windows has remained locked for two minutes, or after every Bitty-Note window has remained minimized or hidden for 30 minutes. Automatic installation waits until every open note has finished saving. Users can disable automatic updates in Settings and check or install updates manually instead.

Opening the GitHub button launches the project page in the user's default browser. GitHub may receive ordinary connection information such as the user's IP address and browser or client metadata. This information is handled under [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

No other information is transferred to networked systems unless the user explicitly requests an action that requires it.

## Changes and questions

Material changes to this policy will be recorded in this file. Questions may be submitted through the project's [GitHub Issues](https://github.com/huangko555/Bitty-Note/issues).

# 隐私政策

最后更新：2026 年 9 月 14 日

Bitty-Note 是一款本地优先的桌面应用，不要求登录账户，也不包含数据分析、广告、遥测或崩溃上报服务。

## 保存在设备上的数据

- 记录以 Markdown 文件保存在用户选择的文件夹中。
- 归档记录保存在 `归档` 子文件夹中。
- 存储文件夹、语言、窗口状态、编辑器设置和更新状态等应用偏好保存在本地。

Bitty-Note 不会上传记录内容或应用偏好。

## 网络访问

启用自动更新后，使用 Velopack 打包的版本最多每 24 小时访问一次 GitHub，以查询 Bitty-Note 的公开版本信息，并静默下载可用更新；手动检查更新也会访问 GitHub。应用下次启动、Windows 锁屏满 2 分钟，或全部 Bitty Note 窗口最小化或隐藏满 30 分钟后，更新会自动安装；安装前会等待所有已打开便签保存完成。用户可以在设置中关闭自动更新，改为手动检查和安装。

点击 GitHub 按钮会使用默认浏览器打开项目主页。GitHub 可能接收到 IP 地址以及浏览器或客户端信息等常规连接数据，这些信息由 [GitHub 隐私声明](https://docs.github.com/zh/site-policy/privacy-policies/github-general-privacy-statement)约束。

除非用户明确发起需要联网的操作，否则应用不会向其他网络系统传输信息。

## 变更与问题

本政策如有实质变更，会记录在此文件中。如有问题，可以通过项目的 [GitHub Issues](https://github.com/huangko555/Bitty-Note/issues) 提交。
