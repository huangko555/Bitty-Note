## 关于 Bitty-Note

随手写下想法、清单和待办。每条记录都会保存为本地 Markdown 文件，方便查看、备份和迁移。

## 功能一览

- **Markdown 直接存储**：记录就是普通 `.md` 文件，不被专有数据库锁定。
- **专注的结构化编辑**：支持一级标题、粗体、斜体、删除线、有序列表、无序列表和任务列表。
- **灵活的列表层级**：不同类型的列表可以混合嵌套，并支持拖动调整内容顺序。
- **记录归档**：可归档暂时不用的记录，也可随时还原；永久删除前会再次确认。
- **目录自由迁移**：可以切换保存目录，并一并迁移现有记录和归档内容。
- **轻量桌面体验**：支持窗口置顶、拖动、缩放、开机自启动和无边框窗口控制。
- **可调编辑体验**：可以选择编辑器字体和字号，并控制标题分隔线、标题及列表标记高亮。

## 记录如何保存

```text
新建一条记录
      ↓
使用结构化编辑器书写
      ↓
直接保存为本地 Markdown 文件
      ↓
继续编辑、归档、迁移或用其他工具打开
```

新用户的默认保存目录是系统“文档”目录下的 `小记一下` 文件夹，归档内容位于其中的 `归档` 子文件夹。应用不维护独立的内容数据库；切换保存目录时，现有记录与归档内容会一起迁移。

## 安装与使用

1. 从项目的 [Releases](https://github.com/huangko555/Bitty-Note/releases/latest) 页面下载 Windows x64 发布包。
2. 解压 `Bitty-Note-v1.0.1-windows-x64.zip`。
3. 运行文件夹中的 `小记一下.exe`。
4. 点击首页右下角的 `+`，创建第一条记录。

应用采用文件夹形式发布，运行时不需要反复解压临时文件。请保留发布包中的其他文件，不要只移动 `.exe`。
