## Bitty-Note

Bitty-Note 是一款用于记录想法、清单和日常待办的轻量 Windows 应用。每条记录都会在本地保存为普通 `.md` 文件，方便直接查看、备份、迁移，也能随时用其他工具打开。

## 功能亮点

- **本地 Markdown 文件**：不使用专有内容数据库，也不需要登录账户。
- **专注的结构化编辑**：支持标题、粗体、斜体、删除线、有序列表、无序列表和任务列表。
- **灵活的内容结构**：不同类型的列表可以混合嵌套，并可拖动调整内容顺序。
- **安全归档**：记录可以归档和还原，永久删除前会再次确认。
- **自由选择存储位置**：切换文件夹时，现有记录和归档内容会一起迁移。
- **适合桌面的窗口控制**：支持窗口置顶、开机自启动、拖动、缩放和无边框窗口控制。
- **可调的阅读体验**：可以选择编辑器字体和字号，并控制标题分隔线及标题、列表标记高亮。
- **英文与简体中文**：软件默认使用英文，可在设置中切换为简体中文。

## 记录始终属于你

```text
新建一条记录
      ↓
使用结构化编辑器书写
      ↓
直接保存为本地 Markdown 文件
      ↓
继续编辑、归档、迁移或用其他工具打开
```

新用户的默认保存目录是系统“文档”目录下的 `Bitty-Note` 文件夹，归档内容位于其中的 `归档` 子文件夹。应用不维护独立的内容数据库；切换保存目录时，现有记录和归档内容会一起迁移。

## 下载与使用

1. 从项目的 [Releases](https://github.com/huangko555/Bitty-Note/releases/latest) 页面下载最新版 Windows x64 发布包。
2. 解压下载的发布包。
3. 运行 `Bitty-Note.exe`，点击首页右下角的 `+` 创建第一条记录。

请保留发布包中的其他文件，不要只移动 `.exe`。使用 Velopack 打包的版本每天检查一次更新；发现新版本后会显示红点，也可以在设置中手动检查。
